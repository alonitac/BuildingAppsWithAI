Key points

    

      
Tool calling is built into the APIs of all common LLM providers (OpenAI, Anthropic, Google…).

      
The LLM only asks for a tool call. The agent runs it locally and immediately sends the output back.

      
The loop depends on tool calls: tool call → loop again. Text only → done.

      
The LLM is stateless: the whole conversation is sent on every turn.
