Welcome to the main repository for the Building Applications with AI Coding Agents course!
This is your place for all course content, exercises, and tutorials.

Work hard, and have fun 😊

## About the course

- **Cursor-first** - Learn Cursor, switching to other AI coding assistants is easy.
- **Build foundations, not "methodology"** - Learn the core concepts and modern tools to work with AI.
- **Cut through the noise** - Focus on what actually works and creates value.
- **Build without coding** - APIs, UIs, and AI Agents.
- **Learn by building** - 5 sessions, 5 demo apps.
